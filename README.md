# JS-divergence
Compute entropy and JS-divergence for two binary datasets with up to 128 variables

- Open the file "main.cpp"
- At the top of the file, replace the value of the variable "unsigned int n = 9;" by the correct number of variables in the data (116)
- Add the files in the input folder
- Compile using "g++ -std=c++11 -O3 ./*.cpp -o JSdiv.out"
- Run using "./JSdiv.out [filename1] [filename2]", replacing [filename1/2] by the actual filename (including extension)
